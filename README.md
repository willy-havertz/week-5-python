# Object-Oriented Programming Challenges

This project demonstrates core object-oriented programming concepts by implementing two challenges:

1. **Assignment 1: Design Your Own Class**  
   A custom class (in this example, a *Superhero* class) is created with unique attributes and methods. A subclass (`LegendarySuperhero`) extends the base class to illustrate inheritance and encapsulation.

2. **Activity 2: Polymorphism Challenge**  
   Multiple classes (i.e., `Car`, `Plane`, and `Boat`) implement their own version of the same method (`move()`), demonstrating polymorphism. Each class provides its own implementation of the method.

## Project Structure

- **fileHandling.py:**  
  Contains the Python code that includes both challenges:
  - The `Superhero` and `LegendarySuperhero` classes (Assignment 1).
  - The `Car`, `Plane`, and `Boat` classes with their `move()` implementations (Activity 2).
  - A `main()` function that demonstrates and tests each part
